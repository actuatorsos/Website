نموذج العمل — Actuators كمنصة B2B

المنصة تبيع خدمات أتمتة وإدارة أعمال جاهزة للشركات الناشئة والفرق التطوعية عبر اشتراكات شهرية مرنة.

◆ مصادر الإيراد
  • اشتراكات شهرية (4 باقات)
  • رسوم خدمات إضافية (SMS، تخزين، API)
  • خدمات استشارية واحترافية
  • رسوم إعداد مخصص للمؤسسات
◆ ما يحصل عليه المشترك
  • قاعدة بيانات معزولة لمنظمته فقط
  • لوحة تحكم كاملة (HR, Finance, CRM...)
  • خدمات حسب الباقة المختارة
  • دعم فني ومجتمع مهني
◆ الشرائح المستهدفة
  • الشركات الناشئة (5-200 موظف)
  • الفرق التطوعية والمنظمات غير الربحية
  • المصانع والورش الصغيرة والمتوسطة
  • مكاتب المحاماة والاستشارات
◇ جدول الباقات
الباقة السعر / شهر الخدمات المستخدمون الدعم
مجاني 0 ر.س الملف الشخصي + المجتمع + التقديم على الوظائف 1 مجتمعي
أساسي 199 ر.س HR + الحضور + الإجازات + CRM حتى 15 بريد إلكتروني
احترافي 499 ر.س الأساسي + المالية + التصنيع + المخزون حتى 50 أولوية + دردشة
مؤسسي 999 ر.س جميع الخدمات + AI Agents + API كامل غير محدود مخصص + مدير حساب

مراحل بناء المنصة

خارطة طريق التطوير على 6 مراحل.

Phase 0 — الأساس
البنية التحتية والمصادقة
إعداد المشروع، SurrealDB schema، نظام المصادقة (JWT)، هيكل الملفات، i18n، Middleware أساسي.
Phase 1 — النواة
الخدمات الأساسية
HR + الحضور + الإجازات + الملف الشخصي + لوحة التحكم. أول tenant يعمل بالكامل.
Phase 2 — التوسع
الخدمات المالية والتصنيعية
الرواتب + الفواتير + ZATCA + المخزون + التصنيع + الصيانة. تكاملات سعودية أولية.
Phase 3 — المجتمع
الشبكة المهنية والتوظيف
المجتمع + التوظيف + CRM + المشاريع + الفعاليات. إطلاق الباقة المجانية.
Phase 4 — الذكاء
وكلاء AI والتحليلات
المستشار القانوني AI + لوحة التحليلات + التقارير المتقدمة + Audit Log.
Phase 5 — النضج
PWA وتطبيقات الموبايل والتحسينات
تطبيقات PWA + أداء + أمان متقدم + GOSI/WPS + Investor Dashboard + API عام.
